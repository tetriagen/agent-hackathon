# Gemini Flash-Lite и локальные правила: проверка пяти PDF

Проверено 14 ноября 2026. Модель: `gemini-3.5-flash-lite`.

**Суммы: Gemini извлёк правильно 9 из 9, локальные правила — 6 из 9.**
Локальные правила пропустили три значения, но не подставили неправильные.
Gemini тоже не подставил неправильных значений в этом прогоне. Это результат
пяти конкретных примеров, а не оценка точности на произвольных счетах.

## Результаты по документам

В таблице суммы перечислены в порядке: выставлено / выплата плана / доля пациента.

| PDF | Сверено по оригиналу | Локальные правила | Gemini |
|---|---|---|---|
| Blue Cross NC | $989.00 / $561.00 / $159.00 | Все три верно | Все три верно |
| HealthComp | $60.00 / $21.77 / $20.00 | Не найдено $60.00; остальные верно | Все три верно |
| Jane Jones, скан | $92.25 / $43.06 / $10.77 | Найдено только $43.06 | Все три верно |
| CMS, пустой GFE | Заполненных сумм нет | Ничего не придумано | Ничего не придумано |
| CMS, учебные примеры | Несколько самостоятельных сценариев | Нет общей суммы пациента | Нет общей суммы пациента |

Оба подхода правильно определили тип всех пяти документов и оставили пустыми
11 полей, для которых нет применимой суммы. Это включает отсутствие GFE-суммы
в трёх EOB. Суммы `patient responsibility` из EOB не являются подтверждением
фактического остатка долга после уже произведённых платежей.

Обновление: новая сверка связанных выплат выявляет расхождение Jane Jones.
Этот отчёт сохранён как результат первоначальной версии; см. [новый прогон](CONSISTENCY-RESULTS.md).

## Что модель упустила

1. **Jane Jones:** на первой странице `TOTAL PAYMENT AMOUNT` = $43.06, но ниже
   `PAYMENT DISTRIBUTION / PROVIDER` = $53.83. Модель выбрала правильное значение
   для запрошенного поля выплаты, но вернула пустой список предупреждений.
   Это расхождение требует проверки; сам пример не доказывает ошибку реального счёта.
   Локальные правила это расхождение тоже не выявили.
2. **Blue Cross:** итог относится к трём claims. Модель не предупредила об этом,
   хотя инструкцией это запрошено. Локальный парсер предупреждение показал.
3. **Цитаты:** для выставленных сумм HealthComp и Jane Jones модель вернула только
   число без заголовка столбца. Числа визуально подтверждены в `CHARGE AMOUNT`,
   страница 1; такие короткие цитаты сами по себе недостаточны для проверки смысла.
   У остальных семи сумм указаны и название поля, и значение. Все девять ссылок
   на страницу 1 соответствуют оригиналам.

Поэтому текущая модель подходит для предварительного извлечения полей.
Автоматическую проверку правильности начислений, покрытий, законности или
обещание экономии этот тест не подтверждает. В приложении AI не меняет
подтверждённые суммы автоматически и не принимает юридические решения.

## Метод и расход

- Контрольные значения записаны до получения ответов модели в
  [pdf-expected.json](../tests/fixtures/pdf-expected.json); в запрос модели они не передавались.
- Gemini получил оригинальные PDF с изображениями страниц. Локальные правила
  использовали PDF.js и браузерный Tesseract OCR. Сравниваются полные способы
  обработки; преимущество Gemini нельзя приписать только пониманию текста.
- Один успешный ответ на каждый PDF. Ответ HealthComp из первоначальной успешной
  проверки повторно использован, чтобы не тратить квоту ещё раз. Ответы не отбирались
  из нескольких удачных попыток и не исправлялись вручную.
- Успешные пять вызовов: **14 880 входных + 945 выходных = 15 825 токенов**.
  Время: **2.20–3.72 секунды на PDF**, суммарно 13.66 секунды по замерам адаптера.
- Выход ограничен 2500 токенами. Нет инструментов, автоматических повторов или
  переключения на более дорогую модель. По умолчанию используется локальный режим;
  удалённый вызов требует отдельного согласия и кнопки.
- Ранее при настройке были неуспешные запросы к 3.8 Flash и проверка недоступной
  для новых пользователей 2.5 Flash-Lite. Их расход неизвестен и не включён в числа
  выше. Сравнения качества больших моделей с Flash-Lite здесь нет.
- Данные бесплатного Gemini API могут использоваться Google для улучшения
  продуктов. В этом прогоне использованы только публичные образцы.
