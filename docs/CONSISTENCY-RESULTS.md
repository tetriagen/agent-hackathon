# Сверка выплат EOB — 15 ноября 2026

ClearBill теперь сопоставляет `TOTAL PAYMENT AMOUNT` с суммой строк
`PAYMENT DISTRIBUTION`. Gemini читает обе секции, а сервер считает разницу
точной десятичной арифметикой. Конкретные суммы образцов в правило не зашиты.

| Публичный PDF | Результат нового прогона | Проверка по оригиналу |
|---|---|---|
| Jane Jones | Расхождение **$10.77** | Стр. 1: итог $43.06; распределение $53.83 + $0.00 |
| HealthComp | Сверка пропущена: одна сумма отсутствует | Стр. 1: итог $21.77 и выплата провайдеру $21.77; сумма строки EMP пустая, не ноль |
| Blue Cross NC | Нет сопоставимой секции распределения | Сумму savings нельзя считать выплатой |
| CMS, пустой GFE | Проверка выплат EOB неприменима | Заполненных сумм случая нет |
| CMS, учебные сценарии | Проверка выплат EOB неприменима | Несколько независимых примеров не объединяются |

Все пять запросов окончательного прогона успешны. Все 9 заполненных контрольных
сумм извлечены верно, 11 неприменимых полей остались пустыми; типы документов — 5/5.
Единственное ожидаемое расхождение найдено; на остальных четырёх образцах ложных
предупреждений о несовпадении нет. Это небольшой проверочный набор, не оценка
точности на произвольных счетах. Локальный парсер без ИИ эту сверку пока не делает.

## Ограничения, обнаруженные при проверке

- В HealthComp модель отметила распределение полным, хотя вернула пустую сумму
  EMP. Сервер отдельно проверяет наличие каждой суммы и поэтому пропускает сверку.
- В Jane Jones модель ошибочно назвала строку EMP получателем `provider`.
  Роль получателя не участвует в суммировании; интерфейс показывает нейтральные
  номера строк. Сами три числа и страницы проверены визуально и верны.
- Некоторые цитаты модели содержат только число без заголовка. Проверка наличия
  числа в цитате не подтверждает смысл секции или подлинность цитаты. Страницы
  оригинального PDF остаются обязательным источником для пользователя.
- Проверяется только одна связь: общий платёж и распределение того же платежа.
  Различные случаи, неизвестная валюта, неполные строки, повторные ссылки на строки
  и неподтверждённая связь секций не дают вывода о расхождении.
- Разница $10.77 — повод запросить объяснение, а не доказанная переплата,
  задолженность, нарушение или обещанная экономия. Совпавшая сверка тоже
  не означает, что весь счёт правильный.

## Расход и воспроизводимость

Использована прежняя **gemini-3.5-flash-lite**, максимум 2500 выходных токенов.
Нет дополнительных вызовов модели для рассуждений, автоматических повторов
или переключения на большую модель. Все проверки арифметики выполняются кодом.

В окончательном прогоне: **16 920 входных + 1 435 выходных = 18 355 токенов**,
суммарно **10.71 секунды** по таймеру адаптера. Результат каждого PDF сохранён
сразу; успешные ответы не отбирались из нескольких вариантов.

При настройке новая сложная схема отклонялась: пять запросов первого пакета и
два диагностических запроса не дали результата; наблюдаемый ответ провайдера —
HTTP 400 `INVALID_ARGUMENT`. Затем был один успешный диагностический запрос
Jane Jones с упрощённой схемой, до окончательного прогона. Его расход не включён
в числа выше. По [документации Gemini](https://aistudio.google.com/docs/structured-output)
ограничения размера вложенных массивов увеличивают сложность схемы. Для запроса
они убраны; строгие ограничения по-прежнему проверяются сервером. Скрипт пакетного
прогона теперь останавливается при первой ошибке, чтобы не тратить попытки.

[Полные ответы и ручная проверка](CONSISTENCY-RESULTS.json) включают хеши PDF,
хеш инструкции, исходные структурированные ответы, сравнение с контрольными
значениями и расход. Публичные PDF и ключи в репозиторий не включены;
источники образцов перечислены в [первоначальном сравнении](GEMINI-COMPARISON.md).

Локальные проверки: 74 Python-теста, существующие проверки JavaScript,
Ruff. В Chromium на искусственных ответах проверены согласие, загрузка,
несовпадение, совпадение, пропуск, страницы источников, вывод текста без исполнения
HTML, неизменность подтверждённых фактов, ошибка квоты и очистка старых результатов.
Ширины 390 и 1440 px проверены визуально: переполнения страницы нет.
Новых обращений к ИИ при проверке интерфейса не было. Ошибок JavaScript нет;
в консоли ожидаемая ошибка ресурса от намеренно подставленного HTTP 429.
