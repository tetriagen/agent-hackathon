# ANEsolves — портфолио веб-проектов

Законченные проекты с исходным кодом, инструкциями запуска и описанием границ реализации.

| Проект | Задача | Реализация | Посмотреть |
| --- | --- | --- | --- |
| [ClearBill](clearbill/README.md) | Помочь пользователю разобраться в медицинском счёте и подготовить запрос на пояснение | Адаптивный сайт, работа с PDF/OCR, FastAPI, проверяемые правила, редактируемые письма | [Живое демо](https://clearbill-5ay0.onrender.com) · [Описание кейса](clearbill/CASE-STUDY.md) |

ClearBill — хакатонный проект ANEsolves, а не выполненный заказ медицинской организации. В кейсе перечислены реализованные функции и ограничения; неподтверждённые показатели продаж, экономии и клиентские отзывы не используются.

## Структура

Каждый следующий проект размещается в своей папке `projects/<project-name>/` с README, исходниками, зависимостями, проверками и инструкцией размещения. Секреты, пользовательские документы, локальные базы и установленные зависимости в портфолио не добавляются.

`clearbill/` — самостоятельный снимок готового приложения. Существующее приложение в корне репозитория продолжает обслуживать Render. Изменения в копии не синхронизируются автоматически с опубликованным сайтом.
